# TalkBot Studio 3.7-SE 구조 검토 개요

솔트룩스 TalkBot Studio 3.7-SE 배포판. 챗봇 빌더(관리도구) + 대화 런타임 + NLU/QA 엔진으로 구성된 마이크로서비스 구조이며, 컨테이너 배포를 전제로 함(호스트명 `api-server`, `chat-server`, `talkbot-db` 등 서비스명 참조, nginx 프록시 설정 포함).

## 구성 요소

| 구성 요소               | 역할                                                     | 기술                                                                 | 포트 (HTTP/HTTPS)     |
| ------------------- | ------------------------------------------------------ | ------------------------------------------------------------------ | ------------------- |
| **talkbot-builder** | 챗봇 제작/관리 웹 UI (SPA)                                    | nginx 정적 서빙 + 리버스 프록시                                              | 80                  |
| **chat-client**     | 최종 사용자 채팅 웹 UI (SPA)                                   | nginx 정적 서빙 + 리버스 프록시                                              | 80                  |
| **api-server**      | 빌더용 백엔드 API. 봇 관리, 사용자, 배포, BI 통계, 스케줄러(Quartz)        | Java (Jetty, Guice, Hibernate+HikariCP, Hazelcast 2차 캐시), 힙 8~16GB | 8000 / 8443         |
| **chat-server**     | 대화 런타임. 배포된 봇 실행, WebSocket 채팅, webhook                | Java (동일 스택)                                                       | 8088 / 8843         |
| **ic-server**       | 의도 분류(Intent Classification). USE/BERT/Sent2Vec 임베딩 활용 | Java                                                               | 6001 / 6443         |
| **qa-server**       | IRQA(검색 기반 QA). MUSE 임베딩(512차원), annoy-server 연동       | Java                                                               | 9090 / 9943         |
| **nlu-server**      | 형태소분석·개체명·시간 표현 등 NLU 엔진. KO/EN/VI 활성(JA 비활성)          | Java (Tanuki wrapper, 네이티브 분석기 라이브러리), 힙 12~18GB                   | REST 3015, API 2915 |
| **plugin-server**   | 사용자 정의 플러그인 실행 (Node.js/Python3 스크립트, 30초 타임아웃)        | Java + node/python3                                                | 9000 / 9443         |
| **annoy-server**    | 벡터 유사도 검색 (Annoy 인덱스, angular, 512차원)                  | Python (Flask/Gunicorn)                                            | 6060                |
| **sbert-server**    | SBERT 문장 임베딩 (slx-bert-v1.0.0 모델)                      | Python                                                             | 5100                |
| **muse-server**     | MUSE 문장 임베딩                                            | Python (Flask/Gunicorn)                                            | (src/app.py에서 설정)   |
| **data/**           | 형태소 사전, NE 사전 등 공용 언어 리소스                              | -                                                                  | -                   |

## 호출 흐름

```
[브라우저]
   │
   ├─ talkbot-builder (nginx:80) ──/api-server/──▶ api-server:8000 ──▶ talkbot-db(MariaDB:3306)
   │        └────────────────────/chat-server/──▶ chat-server:8088      (talkbot_v37_SE)
   │
   └─ chat-client (nginx:80) ─────────────────────▶ chat-server:8088
                                                        │
                              ┌─────────────────────────┼──────────────┐
                              ▼                         ▼              ▼
                         nlu-server:3015          ic-server:6001   qa-server:9090
                                                        │              │
                                              sbert:5100 / muse   annoy-server:6060
```

- api-server가 관리 주체, chat-server가 실제 대화 처리(클러스터 목록: `chat-server:8088`).
- qa-server는 annoy-server(벡터 검색), 외부 USE(5005)/BERT(8125) REST를 참조.
- WebSocket은 nginx 프록시에서 Upgrade 헤더로 지원.

## 주요 설정 위치

- 각 Java 서버: `{server}/config/webServer.properties`(포트), `systemRuntime.properties`(런타임), `mariadb.properties`(DB), `service.sh`(기동 스크립트: start/stop/restart/status).
- nginx: `talkbot-builder/conf/talkbot-builder.conf`, `chat-client/conf/chat-client.conf`.
- NLU: `nlu-server/conf/serverconfig.ini`(포트·언어), `NLU_Server.conf`(JVM·메모리).
- Python 서버: `server.properties` / `config.properties`, `service.sh`(flask/waitress 또는 gunicorn).

## 검토 중 발견된 참고 사항

1. **하드코딩된 외부 IP**: `211.109.9.77`(apiServerURI, 이메일 인증 리다이렉트), `13.21.34.9`(USE/BERT 서버). 환경 이전 시 반드시 수정 필요.
2. **DB 자격증명 평문**: `talkbot / talkbot` (mariadb.properties). keystore 비밀번호도 평문으로 저장됨.
3. **환경 불일치**: api-server·ic-server는 `production`, chat-server·qa-server는 `development`로 설정됨 — 의도된 것인지 확인 필요.
4. **qa-server irqa.properties**: 구버전 흔적(`talkbot-v2.6hae` DB, `nh_bank` 컨텍스트, root 계정 빈 비밀번호) — 실사용 여부 확인 권장.
5. **자체 서명 인증서** 사용(`talkbot_selfsigned.jks`) + `acceptSelfSignedCertificates=true`.
6. **구버전 라이브러리** 다수 포함(jackson-databind 2.9.5, netty 4.1.5, protobuf 2.5.0 등 2017~2018년대) — 보안 검토 시 별도 확인 필요.
7. 모델/데이터 경로가 `/data`, `/opt/models`, `/mnt/talkbot-resources` 등 리눅스 절대경로 기준 — 컨테이너 볼륨 마운트 전제.
