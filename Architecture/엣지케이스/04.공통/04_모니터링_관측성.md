# 모니터링 / 관측성 엣지케이스

## 1. 분산 환경에서 병목 지점 파악 어려움

| 항목 | 내용 |
|------|------|
| **문제** | 하나의 요청이 여러 서비스를 거치므로 어디서 느린지 찾기 어려움 |
| **왜 발생** | 동기/비동기 호출이 혼재된 마이크로서비스 환경 |
| **해결** | 분산 추적(Jaeger/Zipkin), 서비스별 p50/p95/p99 레이턴시 대시보드, 이상 탐지 알림 |
| **핵심 지표** | p99 latency (상위 1% 요청의 응답시간) — 평균만 보면 꼬리 지연(tail latency) 문제를 놓침 |
