# 네트워크 파티션 (CAP 정리) 엣지케이스

## 1. 서비스 간 통신 단절 시 CP vs AP 선택

| 항목 | 내용 |
|------|------|
| **문제** | 네트워크 파티션 발생 시 정합성(C)과 가용성(A) 중 무엇을 우선할 건지 |
| **왜 발생** | 네트워크는 언제든 끊길 수 있음 (CAP에서 P는 전제) |
| **해결** | 도메인별 선택 — 금융 트랜잭션(송금/결제): CP(정합성 우선), 조회/추천: AP(가용성 우선) |
| **금융 예시** | 송금 중 네트워크 파티션 → 이중 송금 방지를 위해 차라리 실패 처리(CP) |
