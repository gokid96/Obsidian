# API Gateway 엣지케이스

## 1. Gateway SPOF (단일 장애점)

| 항목 | 내용 |
|------|------|
| **문제** | Gateway 자체가 죽으면 전체 서비스 장애 |
| **왜 발생** | 모든 트래픽이 Gateway를 거치므로, Gateway 장애 = 전체 서비스 장애 |
| **해결** | Gateway 다중화 + L4/L7 로드밸런서 앞단 배치, Active-Standby 또는 Active-Active 구성 |
| **트레이드오프** | 다중화 시 세션/상태 동기화 비용 증가, 설정 동기화 복잡도 상승 |

## 2. 분산 환경 Rate Limiting 정합성

| 항목 | 내용 |
|------|------|
| **문제** | Gateway 인스턴스가 여러 개일 때 Rate Limiting 카운트가 안 맞음 |
| **왜 발생** | 각 인스턴스가 별도로 카운트 → 실제 허용량 초과 |
| **해결** | Redis 같은 중앙 저장소 기반 카운팅, 슬라이딩 윈도우 알고리즘 적용 |
| **트레이드오프** | Redis 의존성 추가 → Redis 장애 시 Rate Limiting 무력화. 로컬 카운팅은 정확도 떨어짐 |
