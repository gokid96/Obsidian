|항목|Round Robin|Least Outstanding Requests|Weighted Random|
|---|---|---|---|
|**기본 동작**|순서대로 균등 분배 ★기본값|처리 중 요청이 가장 적은 타겟으로 라우팅|가중치 비율대로 무작위 분배|
|**최적 상황**|스펙 동일 인스턴스, 균일한 요청 처리 시간|처리 시간 편차 큼, 인스턴스 성능 차이 있음|카나리/블루그린 배포, 점진적 트래픽 전환|
|**약점**|처리 속도 편차 무시 → 특정 노드 과부하 가능|판단 오버헤드 미세 발생, 단순 환경엔 오버엔지니어링|가중치 설정/관리 필요, 잘못 설정 시 편향 발생|
|**인스턴스 2개일 때**|✅ 충분|➖ 차이 미미|⚠️ 배포 목적 없으면 불필요|
|**운영 복잡도**|낮음|중간|높음|

**결론**: 인스턴스 2개 + 스펙 동일이면 Round Robin 그대로, 처리 시간 편차 크면 LOR, 배포 전략 있으면 Weighted Random.
