## 1. 개요

```
POST /api/v1/email/send 요청
        ↓
verificationRepository.save()   // DB 저장
        ↓
sesV2Client.sendEmail()         // AWS SES API 호출
        ↓  ← HTTP 요청 스레드가 여기서 멈춰서 SES 응답을 기다림
SES 응답 수신
        ↓
200 OK 반환
```

톰캣은 스레드풀(기본 200개)로 요청을 처리하는데, `sesV2Client.sendEmail()`은 외부 네트워크 I/O라서 SES가 응답할 때까지 해당 스레드는 아무것도 못 하고 점유된다. 
SES 응답 시간은 보통 100~300ms인데, 회원가입 요청이 동시에 몰리면 스레드들이 전부 SES 응답 대기 상태로 묶여서 다른 API 요청까지 지연되거나 멈출 수 있다.
