
로그인 후에 워크스페이스에 진입후 폴더들을 조회할때 호출되는 API를 확인

폴더 API 요청
```sql
ubuntu@ip-172-31-60-0:~$ curl -b cookies.txt https://api.untitles.net/api/v1/workspaces/6/folders
...
```

쿼리를 순서대로 보면
**1번** — 로그인 (users 조회 by login_id)
**2번** — workspace 조회 by workspace_id
**3번** — users 조회 by user_id 
**4번** — workspace_member 조회 (권한 확인)
**5번** — 루트 폴더 조회 (parent_id IS NULL)
**6번, 7번** — 자식 폴더 조회 (parent_id=?)
