#### 정합성 / 동시성
```
├── 1. Java/JVM 레벨 동시성 제어
│   │
│   ├── synchronized (기본 단일 JVM 락)
│   ├── volatile     
│   ├── AtomicInteger / AtomicLong / AtomicReference (단일 JVM 원자적 연산 클래스)
│   ├── java.util.concurrent
│   │   ├── Lock / ReentrantLock
│   │   ├── ReadWriteLock
│   │   ├── Semaphore
│   │   ├── CountDownLatch
│   │   └── ConcurrentHashMap
│   │
│   └── ExecutorService / Thread Pool
│
├── 2. DB 레벨 동시성 제어
│   │
│   ├── 원자적 UPDATE (DB)
│   ├── 비관적 락 (JPA)
│   ├── 낙관적 락 (JPA)
│   ├── Isolation Level (DB)
│   └── DB Transaction 
│
├── 3. 분산 환경 동시성 제어
│   │
│   ├── Redis Distributed Lock
│   ├── ZooKeeper Lock
│   └── DB 기반 Distributed Lock
│
└── 4. 분산 트랜잭션
    │
    ├── 2PC
    ├── Saga
    │   ├── Choreography
    │   └── Orchestration
    │
    └── Outbox Pattern
```
