```
- 레거시 코드 수정 없이 로그 파싱만으로 요청ID·송수신방향·메시지유형 구조화
- from/size 페이징으로 O페이지 이상 조회 실패하던 문제를 search_after 전환으로 페이지 깊이 무관 O ms 유지 (예정)
- 전체 건수가 10,000에서 절삭되어 페이지 수가 잘못 표시되던 문제 수정 (예정)
- keyword 필드 ignore_above 기본값으로 256자 초과 로그가 미색인되던 정규식 검색 누락 수정 (예정)
- 검색마다 재계산되던 레벨·유형별 집계를 필터 조건 기준 캐싱으로 중복 제거, 응답시간 O ms 단축 (예정)

알람 수집
- 멀티라인 파싱 방식으로 주기 마지막 알람 블록이 유실되던 문제를 종결자 기반 방출로 수정
- 재시도 불가 응답이 수집기 버퍼를 점유해 후속 알람이 전송되지 않던 문제를 상태코드 정책 변경으로 해결
- 병렬 전송으로 알람 해제가 발생보다 먼저 도착해 소실되던 문제를 전송 동시성 제어로 순서 보장
- 재전송 시 비멱등 연산이 다른 알람을 종료시키는 위험을 실행 순서 변경으로 차단
- 해제 유실로 알림이 반복 발송되던 문제를 미종료 알람 탐지 배치로 개선, 발견까지 수일 → 최대 O분

운영 개선
- 승객 상태 DB 주기 갱신을 Redis Hash 실시간 조회로 전환하여 DB 쓰기 부하 제거
- WebSocket 기반 메시지 적체 현황 및 서비스 연결 상태 실시간 모니터링 구현
- 서버 접속 후 수동 편집하던 프로덕션 config를 웹 편집으로 전환, 콘텐츠 해시 비교로 동시 수정 충돌 차단
```

### RAG 챗봇

```
- tsvector BM25가 한국어 조사를 분리하지 못하는 문제를 bge-m3 sparse 임베딩 도입으로 형태소 분석기 없이 해결
- dense·sparse 검색 결과를 RRF 결합 후 리랭킹하여 Recall@5 O% → O%
- 균질한 문서 본문으로 유사도 임계값 변별력이 없던 문제를 LLM 판정·생성 후 검증으로 대체, 오답률 O% → O%
- temperature 0에도 판정이 뒤집히던 vLLM 연속 배칭 비결정성을 판정 결과 캐싱으로 일관성 확보
- 코퍼스·모델 버전별 지표 이력화로 문서 추가 효과 정량 검증, 오답률 O% 이하를 오픈 기준으로 정의
- BookStack 증분 동기화 및 계층 경로 임베딩 포함으로 동일 제목 페이지 구분
```
