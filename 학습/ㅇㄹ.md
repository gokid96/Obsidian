레거시 현대화

메시지 통계 조회 최적화
- 3일 구간 통계 조회가 1,137만 행 풀스캔으로 22초 소요
  → EXPLAIN으로 집계 컬럼이 인덱스에 없어 테이블 접근이 발생함을 확인
  → 커버링 인덱스 적용 및 동일 조건 2회 스캔을 1회로 통합

로그 조회 통합

- Elasticsearch에서 VictoriaLogs로 전환 — O

알람 수집

- 재시도 불가 응답이 수집기 버퍼를 점유해 후속 알람이 전송되지 않던 문제를
  상태코드 정책 변경으로 해결
- 병렬 전송으로 알람 해제가 발생보다 먼저 도착해 소실되던 문제를
  전송 동시성 제어로 순서 보장
- 재전송 시 비멱등 연산이 다른 알람을 종료시키는 위험을 실행 순서 변경으로 차단
- 해제 유실로 알림이 반복 발송되던 문제를 미종료 알람 탐지 배치로 개선,

사내 문서 기반 RAG 챗봇                                      2025.OO ~ 2026.OO
Python, FastAPI, PostgreSQL/pgvector, vLLM, bge-m3

- temperature 0에도 판정이 뒤집히던 vLLM 연속 배칭 비결정성을
  판정 결과 캐싱으로 일관성 확보
- 코퍼스·모델 버전별 지표 이력화로 문서 추가 효과 정량 검증,
  오답률 O% 이하를 오픈 기준으로 정의
- BookStack 증분 동기화 및 계층 경로 임베딩 포함으로 동일 제목 페이지 구분
