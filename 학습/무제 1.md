# discphy/e-commerce 프로젝트 발전 가이드

`discphy/e-commerce`는 항해플러스 백엔드 코스 과정에서 **10주간 단계별로 발전시킨 대용량 트래픽 이커머스 시스템**입니다. 아래는 프로젝트가 실제로 발전해온 방향과 똑같이 따라할 수 있는 완전한 가이드입니다.

---

## 프로젝트 전체 개요

- **기술 스택**: Java, Spring Boot, JPA, Redis, Kafka, Docker, k6, Prometheus
- **아키텍처**: 클린 아키텍처(DDD) → 이벤트 기반 MSA → 멀티모듈 분리
- **기간**: 2024년 12월 ~ 2025년 7월 (10주 + 리팩토링)
- **브랜치 전략**: `weekN/M` 브랜치 → PR → main 머지

### 🏗️ STEP 2: 클린 아키텍처 비즈니스 로직 구현 (3주차 마일스톤)

|레이어|클래스|요청 DTO|응답 DTO|
|---|---|---|---|
|interfaces|`XxxController`|`XxxRequest`|`XxxResponse`|
|application|`XxxFacade`|`XxxCriteria`|`XxxResult`|
|domain|`XxxService`|`XxxCommand`|`XxxInfo`|
|infrastructure|`XxxRepositoryImpl`|—|—|

**이슈 #13~16 구현 순서:**

1. 잔액 조회 및 충전 (`BalanceService`, `BalanceFacade`)
2. 쿠폰 조회 및 선착순 발급 (`CouponService`, `CouponFacade`)

**핵심 구현 패턴:**

```java
@Component @Profile("test")
public class DatabaseCleaner {
    @Transactional
    public void clean() {
        em.createNativeQuery("SET FOREIGN_KEY_CHECKS = 0").executeUpdate();
        tables.forEach(t -> em.createNativeQuery("TRUNCATE TABLE " + t).executeUpdate());
        em.createNativeQuery("SET FOREIGN_KEY_CHECKS = 1").executeUpdate();
    }
}

// ConcurrencyTestSupport: 재사용 가능한 동시성 실행 헬퍼
protected void executeConcurrency(int threadCount, Runnable runnable) { ... }
```

**엔티티 인덱스 적용 예시:**

**Outbox 패턴 구조 (PR #51 참고):**

java

```java
// 1단계: 요청 → Redis 중복 체크 → Outbox에 카프카 메시지 기록
couponEventPublisher.publishRequested(event); // → OutboxEventPublisher

// 2단계: Kafka 리스너가 수신 후 실제 발급 처리
@KafkaListener(topics = Topic.COUPON_PUBLISH_REQUESTED, groupId = GroupId.COUPON)
public void handle(String message, Acknowledgment ack) {
    couponService.publishUserCoupon(command);
    ack.acknowledge(); // 수동 커밋으로 멱등성 보장
}

// 3단계: 발급 완료 이벤트 → 후속 처리
couponEventPublisher.published(event); // → 도메인 이벤트 발행
```

- `common/message` — Kafka 설정

## 프로젝트 관리 방법 (GitHub 활용 전략)

**마일스톤 설정:** 주차별 마일스톤을 미리 생성하고, 각 이슈에 마일스톤 연결

- `#️⃣ 이슈번호` — 연관 이슈 명시
- `🔗 커밋 링크` — 주요 커밋 해시 직접 링크

**Projects 활용:** 칸반 보드 (`In Progress` → `Code Review` → `Done`)와 타임라인 뷰 동시 운영
