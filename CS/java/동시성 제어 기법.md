ava에서 쓸 수 있는 동시성 제어 기법을 정리하면 이렇습니다.

**기본 락 방식**
- synchronized — 가장 단순, 메서드나 블록 단위로 잠금
- ReentrantLock — synchronized보다 유연, tryLock으로 대기 시간 설정 가능
- userId별 Lock — 위에서 본 것처럼 ConcurrentHashMap + ReentrantLock 조합

**Atomic 클래스**
- AtomicInteger, AtomicLong, AtomicReference 같은 것들로, 락 없이 CAS(Compare-And-Swap) 연산으로 값을 안전하게 변경합니다. 카운터 같은 단순한 연산에 적합합니다.

**스레드 안전 자료구조**
- ConcurrentHashMap, ConcurrentLinkedQueue, CopyOnWriteArrayList 등. 자료구조 자체가 내부적으로 동시성을 처리해줍니다.

**Semaphore**
- 동시에 접근할 수 있는 스레드 수를 제한합니다. 예를 들어 "동시에 5명만 처리"를 걸 수 있습니다.

**CountDownLatch / CyclicBarrier**
- 여러 스레드가 특정 지점까지 기다렸다가 동시에 진행하게 할 때 씁니다. 테스트에서 동시 요청을 시뮬레이션할 때 자주 사용합니다.
