```
내부 통신에서 병목 발생
        │
        ▼
  응답이 바로 필요한가?
    ├─ Yes → gRPC (동기)
    └─ No  → Kafka 같은 메시지 큐 (비동기)
```

항상 gRPC인 건 아님
```
응답이 바로 필요한데 병목이다
        │
        ▼
  병목 원인이 뭔가?
    ├─ 호출 빈도가 너무 높고 JSON 파싱이 부담 → gRPC
    ├─ 네트워크 지연 → 캐싱 (Redis)
    └─ 서버 처리 자체가 느림 → 스케일링이나 코드 최적화
```

```
비동기로 처리해도 됨
        │
        ▼
  어떤 성격의 작업인가?
    ├─ 단순 작업 큐 (이메일 발송, 썸네일 생성)
    │   → SQS, RabbitMQ
    │
    └─ 대용량 이벤트 스트리밍 (로그 수집, 주문 이벤트를 여러 서비스가 소비)
        → Kafka
```
